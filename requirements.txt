# BucketValue dependencies. Exact pins on everything.
#
# The shared set is IDENTICAL to DiamondValue's and GridironValue's so idioms
# port between the three projects without surprises:
#  - pandas held at 2.x on purpose (3.0 changes copy-on-write and default
#    string dtypes, which alters join and parquet round-trip behaviour).
#  - scikit-learn and joblib are pinned to the exact versions the shipped model
#    artifacts in models/ are saved with. Version drift silently breaks
#    joblib.load on a host rebuild. DO NOT bump these two without retraining and
#    re-committing the artifacts.
#  - Streamlit Community Cloud ignores runtime.txt, so every pin here must have
#    a wheel for the newest CPython it might build on (3.14 when checked).

numpy==2.3.5
pandas==2.3.3
